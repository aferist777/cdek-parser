# CDEK Sales

Парсер скидочных товаров cdek.shopping (люкс, духи, одежда, кроссовки)
с локальным веб-интерфейсом.

## Запуск

    run.bat

Откроется http://127.0.0.1:8777 — список товаров, фильтры и панель парсинга.

## Как это работает

Сайт закрыт JS-челленджем: обычный HTTP-запрос получает 503, и даже с
правильными cookies не проходит, потому что WAF проверяет TLS-отпечаток.
Поэтому один раз поднимается Chromium, решает челлендж, отдаёт cookies —
дальше всё качается через curl_cffi, который представляется Chrome.

Данные берутся из плиток каталога (цена, старая цена, процент скидки,
картинка, ссылка). Страницы товаров не открываются вообще. Миниатюра 64×64 —
тот же CDN-URL с другим размером в пути.

Листинги обходятся с `is_sale=1&sort-by=sale_desc`, поэтому порог скидки
обрывает обход рано: `>=50%` — это примерно 2 700 страниц против 37 000 для
всего каталога.

## Панель парсинга

| Параметр | Что делает |
|---|---|
| Скидка от | Порог; обход категории останавливается, когда скидка падает ниже |
| Потоков | Параллельных запросов (4 ≈ 0.7 с/страницу, 8 ≈ 0.4 с) |
| Страниц на категорию | Ограничение глубины; 0 — без ограничения |
| Разделы | Какие корни обходить |
| Бренды | Обходить только выбранные бренды (в разы быстрее) |
| Продолжить прошлый | Возобновить прерванный прогон с чекпоинта |

Прогон можно остановить — он завершится после текущей страницы, а прогресс
сохранится в `data/state.json`.

## Данные

`data/cdek.sqlite`:

- `products` — товары, upsert по `product_id` (дубликаты между категориями схлопываются)
- `price_history` — запись добавляется только когда цена реально изменилась
- `brands`, `category_brands`, `categories` — справочники
- `runs` — журнал прогонов

Экспорт CSV/XLSX — по текущему фильтру, в `data/exports/`.

## Бренды

В плитке каталога бренда нет. Он определяется двумя путями: если обход шёл с
фильтром по бренду — берётся оттуда; иначе распознаётся в названии по
справочнику (2 900+ брендов). Покрытие: люкс 99%, кроссовки 97%, парфюм 92%.

## Утилиты

    .venv\Scripts\python.exe measure.py

Считает, сколько страниц в каждой категории, без самого парсинга. Результат —
`data/volume.json`.
